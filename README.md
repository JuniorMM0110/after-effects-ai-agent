# AE AI — Avances de desarrollo

**Proyecto experimental de automatización y motion graphics para Adobe After Effects.**

Este repositorio es únicamente una **vitrina pública** del proyecto: novedades, resultados y demostraciones. **No contiene el código de desarrollo vigente, instaladores, ejecutables ni paquetes de distribución.** Descargar el ZIP de este repositorio en GitHub no instala el plugin.

## Últimas novedades

Consulta [AVANCES-AE-AI.md](AVANCES-AE-AI.md) para el historial de progreso y las limitaciones pendientes de cada versión.

### Versión 0.5.1 — Motion Review

- Revisión temporal de movimiento a partir de fotogramas reales de After Effects.
- Análisis de cambios entre muestras con métricas de movimiento.
- Controles de contexto de sesión e indicadores de consumo de tokens.
- Generación de instaladores de prueba para macOS y Windows, disponibles **solo en la versión privada del propietario**.

La previsualización todavía es muestreada, no una reproducción continua a fotogramas por segundo completos. Las pruebas finales deben realizarse dentro de After Effects.

## Demostraciones

El directorio [`demo/`](demo/) contiene únicamente imágenes y animaciones de ejemplo del progreso de desarrollo. Estas muestras no son instaladores ni distribuciones funcionales.

## Disponibilidad

El proyecto de instalación y desarrollo completo está mantenido en un repositorio privado del propietario. No se distribuye una versión pública instalable desde esta página.
